## 当前实现

1. `webui/src/components/workbench/SessionWorkbench.tsx:16` 定义 19rem 工作台；摘要和环境信息默认展开，工具、产出和来源默认折叠。实际查看时，长摘要占据主要空间，运行进度不突出。
2. `webui/src/components/workbench/session-workbench-model.ts:30` 的模型包含摘要、环境、差异、MCP、CLI、产出和来源，没有独立任务、计划、Skill、记忆、子 Agent 字段。
3. 同文件从最后一条 assistant 正文生成摘要，通过 trace 中的 `mcp_` 名称和两个 CLI 名称统计工具调用。因此“技能与 MCP”目前并不等于已接通 Skill 生命周期；调用次数也不能直接解释为成功次数。
4. `webui/src/components/thread/ThreadShell.tsx:2116` 的工作台外层使用 `hidden md:flex`。窄窗口实测不可见；工具侧边栏开关虽能变更选中状态，也没有可见面板。
5. 同文件已有独立子 Agent 面板，工具坞会覆盖工作台整列。后续应共享现有状态来源，避免另建一套互相不一致的展示。

## 建议的信息层级

- 默认“进展”：一句摘要、任务完成情况、运行任务、可展开的当前计划与子 Agent。
- “记忆”：区分工作记忆与长期记忆，显示来源、更新时间及保存状态；不能把暂存文字标成已持久化。
- “能力”：独立展示 Skill 加载/使用情况；MCP 区分连接状态、实际调用与调用结果。
- 环境、产出和来源保留折叠入口，减少默认占位。
- 窄屏提供可打开的抽屉或替换视图；桌面工具坞与工作台的切换状态保持明确。

## Demo 与真实接入边界

`session.html` 为零依赖的静态交互原型，使用明确标注的示例数据。支持三页签、任务筛选与详情、模拟任务状态变化、计划展开、子 Agent 状态派生、记忆详情、能力详情、侧栏收起、宽度及主题切换。刷新会恢复示例；输入不会发送模型请求。

真实接入需进一步核对当前会话的任务/plan、子 Agent 事件、记忆读写、Skill 加载与工具结果事件，定义稳定的会话级状态映射。当前调查只能确认前端聚合缺口，不能据此断言后端所有能力均不存在。
