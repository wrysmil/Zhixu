# 发布值班手册（2026 Q4）

## 灰度发布

新版本按三批灰度：
1. 第一批放 **5%** 流量，观察 **15 分钟**；
2. 第二批放 **30%** 流量，观察 **30 分钟**；
3. 全量发布前必须确认错误率低于 **0.5%**。

```bash
kubectl set image deployment/web-api web-api=registry.local/web-api:v2.7.3
kubectl rollout status deployment/web-api --timeout=10m
```

## 故障升级

| 级别 | 触发条件 | 升级对象 |
| --- | --- | --- |
| P2 | 错误率 0.5%–2% | 值班一号 |
| P1 | 错误率超过 2% 或支付不可用 | 值班二号（电话 021-6688-9900） |
| P0 | 全站不可用 | 值班二号 + 技术负责人 |

升级时必须在 **10 分钟**内完成电话确认，并在事故群同步。

## 发布窗口

允许发布的时间为工作日 **10:00–16:00**；周五 16:00 后与法定节假日前一天禁止发布。
